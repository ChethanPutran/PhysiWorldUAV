## 0. Map of the repo (data flow)

```
config/*.yaml (Hydra) ─► experiments/plan.py (manifest row = whole episode) ─► runner.py (Isaac+OmniDrones, 200 Hz PhysX,
   WrenchInjector aero truth, IMU) ─► data/recorder → writer.py (HDF5 shards, schema v2) ─► index.json (split_role per group)
        │
        ▼
data/dataset_builder.py  load_model_episodes(): decimate ×4 → Δt = 20 ms; states p|v|q|ω_B, obs = clean IMU, actions = mean rotor speed
        │                (filter: status=="completed", applicability_ok, no body_wrench open-loop)
        ▼
data/dataset.py ModelReadyDataset  window t: state_hist[t-H+1..t], obs_hist, action_hist[t-H..t-1], future_actions[t..], future_states[t+1..]
        │  + data/noise.py ImuNoise (white + per-window bias, applied to obs_history at load time)
        ▼
training/run.py → trainer.py   fit_stats(train) → build_model → curriculum [1,5,10,20] → AdamW+warmup/cosine → val_id each epoch
        │  models/world_model.py (B0–B6) · models/physics.py (f_phys, RK4) · models/quat.py · losses/losses.py
        ▼
checkpoints/best.pt ─► evaluation/run.py (per split role) ─► evaluator.py (open loop, physical units) ─► analysis.py / report.py
```
Key semantics: B3 rollout = `rk4_step(f_phys + d_θ(h, s, u))`, h updated by `GRUCell([E(φ(ŝ_{t+1})), u_t])` where φ = synthetic IMU `[Rᵀ(v̇+g), ω̂]`; encoder runs over a 10-step noisy-IMU history from h₀ = 0; rollout starts from the **given clean true state** at window end.

### Items checked and found correct (no finding)

- **f_phys**: thrust along body +z rotated by R(q) (body→world), gravity −z (z-up ENU), torque `τ = (Σ ry T, −Σ rx T, s·Σ dir·km Ω²)` equals `r × F`, gyroscopic term `−ω×Jω`, `q̇ = ½ q⊗[0,ω_B]` (body frame), residual `δ` enters only the kinematics (`physics.py:216-232`).
- **Quaternion convention vs data**: finite-difference of the stored (q, ω) matches right-multiplication with ω_B with mean error 4.8e-4, left-multiplication (ω_W) would give 3.4e-2 ⇒ stored ω is body-frame as the models assume. `dp/dt` vs mean v: 6e-4.
- **RK4** (`physics.py:249-273`): correct weights, control held constant, renormalisation of stage inputs and result.
- **State/action alignment**: one-step f_phys prediction on no-wind episodes with the action shifted by −1/0/+1 gives mean |Δω| 2.26e-3 / **1.67e-3** / 2.42e-3 (shift 0 best, i.e. `actions[t]` produces `states[t+1]` as documented). Velocity is not sensitive (near-hover thrust).
- **Window construction** (`dataset.py`, `window_starts`): no windows cross episode boundaries; history/horizon indices match the docstring; `observe()` pairs `o_j` with `u_{j-1}` in the recurrence, identical to `couple()` in imagination (`world_model.py:173-182` vs `210-214`).
- **Split hygiene**: 0 of 23 counterfactual groups appear in more than one role; 0 domains in more than one role; 0 scenario ids in more than one role. (One reference-serialisation key appeared in two roles in `t_data2.py`, but I truncated the key to 200 characters, so this is most likely a truncation artefact — **not verified**.) Normalisation stats and loss weights are fitted on `train` episodes only and stored in the checkpoint (`trainer.py:186-191`, `snap["stats"]`); evaluation reloads them from the checkpoint.
- **No leakage in imagination**: rollout uses only `future_actions`, the given last state, and the history IMU/actions; `future_states` / `future_obs` are touched only when an `Anchor` is passed (`t_model.py`: outputs bit-identical under perturbation). The decoder is only used in the loss and with `initial_state="decoder"`.
- **Residual**: mask `acc_only` zeroes ṗ and attitude-rate channels exactly (measured mean |r| = 0 on channels dp, dθ; 0.07 / 0.15 on dv, dω); the dec-only loss produces zero gradient in the residual net; APHYNITY penalty is detached for logging only; no truncation/detach in BPTT (full-horizon gradients).
- **Loss**: quaternion geodesic (no angle wrap problem), per-term weights = 1/(hold-last-state baseline, floored) on train windows, rollout term divided by Σγ^k; no padded steps exist; no teacher forcing (`trainer.py:238`).
- **Train/eval mode**: no dropout/batch-norm; φ noise generator is seeded in eval (`model.eval()` ⇒ deterministic: verified `torch.equal`).
- **Numerics**: float32 vs float64 RK4 after 50 steps (aggressive rates): max diff 1.2e-6; torque-free asymmetric-body rotation conserves energy to 2e-7 and |Jω| to 7e-8 over 500 steps.

## 2. Top 5 issues most likely to invalidate the thesis results

1. **F1/F2 — wrong checkpoint evaluated for B2, B4, B4_rw, B5a, B5b.** The test numbers do not belong to the best-validation models, the narrative "not a checkpoint bug" is wrong, and the bug only spares B3, so the B3-vs-baseline margins (e.g. B3−B4 −34 % on val, −13 % vs B4's real best) are inflated. Every ranking in `baseline_comparison_pilot_v05_v06.md` must be regenerated after a fix and retraining.
2. **F3 — 0.2 s zero-initialised latent context** cannot identify vehicle parameters or wind, which is the premise of the "memory" contribution. The measured B3 ≈ B1 on OOD wind is what one would expect; the thesis claim about latent memory is currently untested at a meaningful context length.
3. **F4/F5 — optimistic and asymmetric protocol**: rollouts start from the perfect clean state, the decoder path is never evaluated, and real-IMU bias is present in the observation phase but absent from φ in imagination.
4. **F6/F7 — evaluation cannot discriminate**: 0.4 s horizon, a reliable-horizon metric saturated at K for all models, window-pooled RMSE, 2–7 episodes in OOD roles, one seed.
5. **F9/F8 — thin, narrow training data and unequal budgets**: 63 training episodes with small tilt/rate coverage, grounded episodes dropped, B6b trained to a different stopping point; conclusions about OOD generalisation rest on very little diversity.
